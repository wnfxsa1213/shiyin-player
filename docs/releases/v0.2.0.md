# 拾音 v0.2.0

本版新增可保存和轮换的视觉场景，统一主界面与沉浸播放的队列操作，并完善播放失败恢复和推荐反馈。

## 新功能

- 八套视觉场景：星海、雨夜、初雪、萤火、流星、气泡、花信、共振。
- 支持 JPEG、PNG、WebP 自定义背景和专辑封面背景，可预览、应用、另存搭配并加入随机轮换。
- 场景随音乐变化，自动调整画质；隐藏窗口和减少动态效果时停止不必要的绘制。
- 播放单曲保留队列，播放全部明确替换队列；指定下一首优先于单曲循环和随机模式。
- 队列支持当前歌曲定位、虚拟滚动、键盘操作和清空确认。

## 修复与改进

- 沉浸播放的上一首、播放/暂停和下一首沿用主播放队列，待播放队列可直接启动。
- 加载、缓冲和自动重试提供持续状态反馈；失败后可重试正确的歌曲。
- 修复暂停竞态、失败循环和恢复播放时跳回零秒的问题。
- 修复沉浸预览在未播放或暂停时变成静态画面的回归；预览与正式播放共用歌词布局和背景遮罩。
- 修复从队列进入沉浸界面时的焦点交接，以及隐藏或加载后的迟到频谱处理。
- 完善双音源推荐聚合、部分音源不可用时的降级反馈、空结果恢复和电台提示去重。

## 安装

Ubuntu / Debian 下载 `ShiYin_0.2.0_amd64.deb` 后安装：

```bash
sudo apt install ./ShiYin_0.2.0_amd64.deb
```

AppImage 下载后添加执行权限并运行：

```bash
chmod +x ShiYin_0.2.0_amd64.AppImage
./ShiYin_0.2.0_amd64.AppImage
```

## 已知范围

本版面向 Linux x86_64。高分辨率视觉场景仍有长帧，普通集显、8GB、60Hz 设备的性能验收尚待完成。在线曲目可用性取决于音乐平台、登录状态及账号权限。
