# 播放主流程 UI 与交互统一

2026-09-06 已实现，位于 `codex/ui-interaction` 开发分支，待评审。范围为播放栏、歌曲入口和播放队列；沿用播放生命周期，Radio session、Lyrics read-model 与后续压力测试继续暂停。结果与界面截图见 [验证记录](playback-ui-validation.md)。

## 页面方案

播放栏采用实色表面和固定的三段布局。左侧封面、歌名、歌手与状态；中央播放控制与进度；右侧场景入口、队列数量与音量。状态更新不改变主控制按钮的位置。失败后在播放栏上方增加持续可见的一行恢复区，内容区域随之缩小，不遮挡列表最后一行。

```text
                                         播放队列 · 28    关闭
                                         列表循环 / 单曲循环 / 随机
                                         定位当前歌曲      清空
                                         当前选择 · 第 12 首
                                         12  歌名 / 歌手     移除
                                         13  歌名 / 歌手     移除
────────────────────────────────────────────────────────────────
无法播放「歌曲 B」 · 原因                         重试这首   关闭
────────────────────────────────────────────────────────────────
封面  歌曲 A / 歌手          上一首  暂停  下一首    场景 队列 音量
      正在播放               0:42 ━━━━━━ 3:28
```

队列是非模态侧面板，使用虚拟滚动；打开时定位当前选择，后续切歌不主动抢走阅读位置。定位按钮、方向键与 Home/End 可到达未渲染的条目。移除后保持相邻条目的键盘焦点。当前选择使用强调色和文字标识，正在加载时不冒充实际播放。

## 操作契约

| 入口 / 操作 | 行为 |
| --- | --- |
| 歌曲行单击 | 聚焦歌曲行，不切歌 |
| 歌曲行双击、行上 Enter / 空格、显式播放按钮 | 播放这首，保留队列；已经在队列的歌曲不重复添加；当前歌曲保持播放或恢复暂停 |
| 推荐卡片、最近播放卡片 | 单击或 Enter / 空格播放这首，与歌曲行共用动作 |
| 更多按钮、右键、Shift+F10 | 打开同一歌曲菜单，支持方向键、Home/End、Escape 与关闭后焦点返回 |
| 下一首播放 | 把歌曲移到当前项后，不重复添加；一次指定优先于随机和单曲循环，播放后恢复原模式；当前项不重复安排 |
| 加入队列 | 追加去重，不自动切歌；已存在时明确提示 |
| 播放全部 / 随机播放全部 | 明确替换队列，分别切换列表循环 / 随机；页面持续注明替换结果 |
| 队列条目 | 单击或 Enter / 空格播放；方向键与 Home/End 只移动焦点 |
| 移除当前项 | 播放剩余的下一项；最后一项移除后停止，保留既有生命周期策略 |
| 清空队列 | 内联确认明确“清空并停止”；取消与完成后恢复焦点 |

## 状态与恢复

| 事实 | 表达 |
| --- | --- |
| 空队列 / 已加入但尚未播放 | 未在播放 / 队列待播放，队列有歌曲时播放按钮可开始 |
| 加载 | 正在加载；封面和歌名对应目标歌曲，旧曲目仍在发声时补充说明 |
| 加载或缓冲时暂停 | 已暂停，说明就绪后保持暂停；按钮可恢复 |
| 缓冲 | 缓冲中及进度，不误显示正在播放 |
| 自动重试 | 正在重试及次数，沿用最多两次的既有预算 |
| 播放 / 暂停 / 停止 | 持续可见的状态文字；暂停请求尚未落实时表明正在暂停 |
| 最终失败 | 保留失败歌曲和友好原因，可重试这首或关闭提示；即使已回滚上一首，也不会把错误归给上一首 |

失败事实与恢复动作属于 `createPlaybackLifecycle`。界面只读状态和调用动作；迟到失败不覆盖新选择，清队列与主动选曲清除旧失败。保留自动跳过和回滚策略，界面不额外发起重试。

`playTrack`、`playAll` 收敛各入口的队列操作；`retryPlayback` 明确创建新的播放尝试，即使失败回滚到了同名同源歌曲也会执行重试。`nextQueuedKey` 表达最近一次指定的下一首，选中、移除或清空后消除；普通追加仍去重。

主界面与沉浸播放共用状态和失败恢复组件。播放失败与自动重试不再重复弹出 Toast；沉浸状态位于曲目信息区，失败时控制栏保持可见。暂停、跳转和音量操作失败仍保留原有错误提示。

播放栏通过正常布局占位，失败区出现时内容和队列同步缩小；没有额外绘制循环。修正 WebKit 滑块轨道选择器，音量显示已设置的比例；无有效播放尝试时禁用进度条，并为读屏提供时间值。

## 验证

功能回归覆盖单曲保留队列、全部播放替换、去重与下一首优先、快速切歌、失败回滚和重试、清空取消迟到请求、菜单与队列焦点。构建与已有生命周期测试继续执行。界面按 1200×800 和 900×600、深浅主题检查；本轮不运行压力测试。
